# Мои дела

Первый учебный проект: список дел на русском языке. Можно добавлять задачи,
отмечать выполненные, переключать фильтры и удалять ненужное.
Зависимости и регистрация не нужны.

## Как открыть

Самый простой способ на своём компьютере (после отправки файлов в GitHub):

1. На странице репозитория в GitHub нажми **Code → Download ZIP**.
2. Распакуй архив целиком.
3. Открой `index.html` двойным щелчком в обычном браузере.

Если браузер запрещает открывать локальные страницы или сохранять их данные,
используй локальный сервер ниже. В облачной среде проверена работа через сервер;
прямое открытие файла здесь запрещено политикой браузера.

Для разработки в среде с Python можно запустить локальный сервер:

```sh
cd /workspace/Test
python3 -m http.server 8000 --bind 127.0.0.1
```

На своём компьютере перейди в папку проекта вместо `/workspace/Test`.
Открой адрес сервера, который напечатает команда, в браузере на том же компьютере.
Остановка сервера — `Ctrl+C`. Сервер в облачной среде сам по себе не публикует сайт в интернете.

## Попробуй за пять минут

1. Добавь «Разобраться с первым проектом» кнопкой **Добавить** или клавишей Enter.
2. Добавь вторую задачу и отметь первую галочкой.
3. Переключись между **Все**, **В работе** и **Готово**.
4. Обнови страницу: задачи должны остаться.
5. Удали задачу крестиком или нажми **Убрать готовые**.

Задачи сохраняются в `localStorage` — небольшом хранилище браузера.
Они не отправляются на сервер, не попадают в GitHub и не синхронизируются
между устройствами. Очистка данных сайта удалит задачи. В приватном режиме
или при запрете хранилища сохранение может быть недоступно; приложение покажет предупреждение.
Для одинакового хранилища открывай проект одним и тем же способом и по тому же адресу.

## Как устроен проект

| Файл | За что отвечает |
| --- | --- |
| `index.html` | Содержание страницы: заголовок, поле ввода, кнопки и список |
| `styles.css` | Внешний вид: цвета, размеры и расположение элементов |
| `app.js` | Действия: добавление, выполнение, удаление и сохранение задач |
| `README.md` | Эта инструкция |

Браузер открывает HTML, затем подключает CSS и JavaScript.
Например, при нажатии «Добавить» JavaScript читает поле ввода,
добавляет задачу в массив, сохраняет его и обновляет список на экране.

## Как учиться вместе с Codex

Давай небольшие конкретные задания, проверяй результат и задавай вопросы:

- «Объясни функцию render в app.js простыми словами».
- «Измени зелёный цвет кнопки на синий и покажи, где он задаётся».
- «Добавь возможность редактировать текст задачи».

Исходные файлы проекта и твои задачи — разные данные. Git хранит историю
файлов проекта; браузер хранит введённые задачи.

## Как связаны изменения и GitHub

1. Измени файл и проверь страницу в браузере.
2. Посмотри разницу (diff): что добавилось и что удалилось.
3. Создай **коммит** — сохранённую версию с понятной подписью.
4. Отправь коммит в GitHub (**push**), чтобы он появился на сайте.

**Ветка** позволяет работать над изменениями отдельно. **Pull request (PR)**
показывает изменения перед их объединением с основной веткой `main`.
Публикация работающего сайта — отдельный шаг; наличие файлов на GitHub
ещё не делает страницу общедоступным сайтом.
